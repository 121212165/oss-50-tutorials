## 它是什么（30 秒版）

chinese-poetry 是最全的开源中文古典文集数据库：从《诗经》、楚辞、论语，到唐诗宋词元曲、古文观止，累计超过 42 万首诗、5 万余首词，总计约 5.5 GB 的结构化数据。全部以 JSON 文件按朝代/作者分卷存储，无版权风险，是 NLP 中文研究里被广泛引用的语料库。对写作者来说，它是一座可以直接下载的"中文母语审美原料矿"。

## 为什么对你超有帮助（结合你的具体项目说）

你的 novel-ai-writing-system 里最难的是定义"人味到底是什么样"。现代网文语料本身被 AI 大量污染，而古典诗词是**时间检验过的纯人写语料**——这正是你三件武器的对照系：

1. **AI 味检测的"人写基线"**。拿唐诗宋词（连同不同作者间的差异）做真实人类写作多样性的参照：人类作者句长分布、意象词复用率、节奏变化长什么样？把 AI 生成的女频文和这个基线对比，比拍脑袋定阈值科学得多。
2. **作者指纹的训练素材**。同一诗人在不同作品中的用词惯性（李白的"月"、杜甫的对仗密度）是天然的"作者指纹样本"。做指纹模型前，先在诗数据上验证"同一作者的文本特征分布是否可聚类"——数据干净、作者标注确切，是最理想的实验台。
3. **去 AI 味管线的审美弹药**。女频文需要意境：章节名化用诗词、描写段引用意象。这个库让你能程序化检索"写离别/月夜/悔恨的句子"，做一个"随机化用"模块，输出比模型现编的更有人味。
4. **μ̂/字数之外的节奏研究**。近体诗有严格的字数与平仄约束，是研究"受控节奏"的绝佳样本，可反哺你对"句长方差"等节奏特征的理解。

## 架构拆解（核心模块 + 数据流）

仓库本质是"JSON 文件树 + 约定字段"，没有代码框架，谁都能直接读：

- **目录结构**：按文体分一级目录——`json/`（唐诗宋词等，按作者分文件如 `poet.tang.0.json`）、`shi/`（诗经楚辞）、`lunyu/`、`mengxue/`（蒙学）、`wudimingju/`（五朝名句）等，另有 `chinese-poetry-data` 分支提供 zip 打包整库下载。
- **数据模式**：每个 JSON 文件是一个数组，元素含 `title`、`author`、`paragraphs`（正文句组）、`dynasty` 等字段。同一套字段约定贯穿全库，解析器可以复用。
- **组织方式**：大规模数据按"作者+序号"切片（每个文件几千首），避免单文件过大；来源均为公共领域古籍整理。
- **生态**：社区有配套的 Web 检索站、多语言移植版，以及各类"每日一诗"App 以它为数据源。

数据流极简：clone 仓库 → glob 文件 → json.load → 喂给你的 DataFrame/统计代码。

## 上手路径（第一步做什么，命令级）

```bash
git clone --depth 1 https://github.com/chinese-poetry/chinese-poetry.git
cd chinese-poetry
python -c "
import json, glob
files = glob.glob('json/poet.tang.0.json')
data = json.load(open(files[0], encoding='utf-8'))
print(len(data), data[0]['title'], data[0]['author'], ''.join(data[0]['paragraphs'])[:50])
"
```

第一步：读通唐诗目录下任一文件的字段结构。第二步：写脚本加载全部唐诗，统计每个作者的"意象词表"（月/花/夜等高频名词），跑一次聚类看能否按作者分组。第三步：挑 20 个女频常用情境（重生、退婚、雪夜诀别），建一个"化用素材索引"。

## 进阶玩法 / 避坑

- **进阶**：结合 jieba 分词对全库做词频 n-gram 索引，做成可查询的"古典用词数据库"给去 AI 味管线调用；用五朝名ju目录做随机"今日化用"推送；把宋词词牌的长短句结构提取出来，作为节奏特征的极端样本。
- **避坑**：① clone 全库很大（GB 级），只要诗的话用 `--depth 1` 或只 sparse-checkout 需要的目录，或直接下 data 分支的 zip；② 部分文件编码与标点有历史整理瑕疵，统计前先做清洗（全角/半角、异体字）；③ `paragraphs` 里标点与分行是整理者加的，研究"原始书写"时要留意；④ 数据只到古典时期，直接当"现代文风基线"会有代际偏差——当审美参照系用，别当分布基线硬套。

## 横向对比：为什么是这个不是别的

中文语料库的黄金组合：chinese-poetry（古典审美基线）+ 现代网文爬取样本（当代叙事节奏）+ 你的私稿（作者指纹）。单用任何一个都会有盲区——古典太远、网文被 AI 污染、私稿量太小。三个坐标一起定，才能测出"人味"的真实位置。

## 认知红利：这篇能改变你什么

"被时间检验过的纯人写语料"这个概念会刷新你对数据集的认识：数据的最高价值不是大，而是"标注可靠 + 无污染"。你挑训练素材、评测金标时的洁癖，应该向唐诗宋词的标准看齐。

> 冷知识：仓库里有 5.5 万首唐诗、26 万首宋诗——但全库最常被引用的可能只是"月"字的出现频次统计：好数据集的价值，在于它能回答你提得出来的问题。
