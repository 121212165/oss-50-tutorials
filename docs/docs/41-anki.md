## 它是什么（30 秒版）

Anki（3.1 万 star）是桌面版 Anki 的完整源码（Rust 核心 + Qt 界面 + Python 胶水），Anki 本身是间隔重复记忆卡的鼻祖级软件：多平台免费、全功能、数据（.apkg）通用，全球医学生、语言学习者、程序员的记忆外挂。这个仓库让你能看穿一个运营 20+ 年、跨六大平台、拥有庞大插件生态的开源产品是怎么造出来的。

## 为什么对你超有帮助

你在做学习类应用（formula-challenge、etymology-app、fangji-mnemonic-game），Anki 是这个品类里最值得解剖的活体。三个观察点：①**同步架构**：Anki 的多端同步（桌面/手机/Web，离线优先、冲突处理、端到端可选）是个人开发者的天花板级参考——你的学习类应用迟早要做"多设备继续学"，先看 Anki 的 sync 协议设计（增量同步、变更日志、乐观锁思路），比你从零拍脑袋强太多；②**插件生态的接口设计**：Anki 的 addon 体系（Python 钩子点）撑起了数千个插件（包括第 40 篇的 FSRS 插件），"核心保守 + 钩子开放"的平衡术，正是你给 Obsidian 插件和自己的应用规划扩展性时的最佳参照；③**产品长跑启示**：Anki 是个人项目（Damien Elmes）运营二十年的样本——不为融资、不为增长曲线，靠核心价值 + 可持续的商业模式（iOS 版收费养全线）活成基础设施。你把写作系统当十年事业来做，这种"慢产品"的经营样本很珍贵。

## 架构拆解

一个跨平台产品的分层活教材：①**Rust 核心（rslib）**：牌组、卡片、复习调度、同步逻辑全部下沉到 Rust 库——"业务核心与 UI 无关"，这让它能同时喂饱 Qt 桌面、AnkiDroid（Java 调 Rust FFI）、AnkiMobile；②**FTL 国际化**：所有界面文案走 .ftl 文件（Fluent 格式），社区翻译即改文本文件——你做中英双语应用（sleepquiz 做过）可以直接抄这套文件组织；③**存储层**：数据是 SQLite 单文件（collection.anki2），schema 迁移、备份、损坏恢复都围绕单文件设计——你的 node:sqlite 应用（静界）同路线，很多问题 Anki 已经替你踩过；④**协议与渲染**：复习界面是 Web 技术渲染（HTML 模板 + CSS），桌面壳只是容器——"原生壳 + Web 内容"是跨平台开发的经典折中。数据流：UI 动作 → py 胶水 → rslib 业务 → SQLite → 同步协议上云。

## 上手路径

第一步：先当用户：装桌面版 Anki，建一个"开源项目 50 课"牌组，把本教程站每篇的三个要点做成卡片，用 FSRS 调度复习一周——产品体验即调研。第二步：clone 仓库跑一次本地构建（docs/development.md 有全流程，Rust + Python 环境要求写在里面）。第三步：读 rslib 的 deck/card 数据结构定义，对照你 formula-challenge 的数据模型找差距。第四步：写一个 50 行的 Anki 插件（改复习按钮文案），体会钩子机制。

## 进阶玩法 / 避坑

避坑一：Anki 源码体量大（Rust + Qt + Web 三栈），通读不现实，带着具体问题（同步怎么做、调度在哪、模板怎么渲染）定点读。避坑二：别在标准库里魔改，需求走插件。进阶：给你的 formula-challenge 做"导出 .apkg"功能（apkg 本质是 zip + SQLite + 媒体目录，格式有文档），让你的用户把卡片带进 Anki 生态——与基础设施兼容而非对抗，是小产品最聪明的获客姿势。

## 横向对比：为什么是这个不是别的

记忆产品谱系：Anki（本地、自由、极客味）、Quizlet（云端、易用、商业）、Memrise（课程化）。Anki 的护城河是"数据在你手里 + 算法最优 + 全平台免费"——学习工具的终极形态之争，其实是数据主权之争，和你的 Obsidian 选择同源。

## 认知红利：这篇能改变你什么

Anki 二十年不倒的经营模式值得细品：桌面全功能免费、iOS 版收费养活全线、数据格式开放——"核心免费 + 便携场景收费 + 开放格式"的组合，是独立开发者可持续的范本，你的写作系统想长跑，这套账要提前算。
